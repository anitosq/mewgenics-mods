# Good Genes 0.3.2

Fixes mismatched ordinary eyes, legs and other paired parts in kittens. Asymmetric inheritance now applies only when either inherited side has a mutation; ordinary pairs use the game's normal mirroring.

Single-sided and split mutations remain preserved. Each pair is handled separately, so a mutation in one pair does not make unrelated ordinary pairs asymmetric.

Close the game before updating. Install and enable the archive through your mod manager, with both the native DLL and asset entry enabled. Requires Mewjector API 3 or later and Windows Steam build 1.1.21239 / 25143593.
