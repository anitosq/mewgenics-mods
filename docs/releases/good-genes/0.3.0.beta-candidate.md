# Good Genes 0.3.0.beta candidate

Prepared 2026-10-11 for owner testing of guaranteed parental skill inheritance.
No installation, save changes, push, tag or publication. Official 0.2.0 and all
previous candidate archives remain unchanged.

## Changes

- Select up to two distinct normalized active skills and one eligible passive
  from the parents' combined unique pools, without Stimulation odds or class bias.
- An empty parent or duplicate skill cannot waste an available inheritance pick.
  No slot expansion or guarantee of copying every parental skill.
- Preserve active upgrade removal, ordinary Skill Share exclusion and native
  Skill Share+ handling. Use the native passive setter and refresh active birth
  copies afterward, including any active skills granted by that setter.
- Keep initialized skills when no eligible pool exists or native data cannot be
  read safely. Existing kittens, overnight mutations and mutation choices are
  unchanged. Reuse the existing birth hook; no additional entry detour.

## Evidence And Limits

Inspected the supported executable's constructor, skill selection, normalizer,
passive setter and TLS RNG paths. The normalizer needs a 0x28-byte output,
including its trailing upgrade integer; the native passive setter consumes its
owned string. Both new gates replace whole instructions and retain the TLS
setup and xmm9 initialization used by later birth processing.

Clean committed source compiled with warnings treated as errors. Packaging
validated ten allowlisted files and FOMOD mappings. The frozen archive and all
payloads matched the manifest through `tools/verify_mod_archive.py`. Version,
startup text, ZIP name and package metadata agree on `0.3.0.beta`.

Regression checks were authored but not run. No DLL loading, game launch,
installation, save editing, gameplay checks or runtime profiling was performed.
Compilation and static inspection do not establish native runtime correctness.

Owner checks: breed with low/negative and high Stimulation, one empty parent,
duplicate/upgraded actives, and no eligible skills. Include Skill Share+ and
passives granting active skills, then save/reload and breed the next generation.
Keep the beta label until owner testing is confirmed.
