Good Genes 0.2.0 adds choices for stat trade-offs and shows how a replacement changes your cat's stats.

- Stat-only replacements that raise some stats and lower others now open Keep Existing / Replace. Clear improvements remain automatic; equal changes and pure downgrades keep the current mutation.
- Both columns show inherited base stats plus active mutation bonuses for the entire change. Incoming increases are green, decreases red, and unchanged values retain their color.
- Full descriptions replace text paging. Arrows remain only between different affected parts.
- Head changes account for facial mutations they hide or restore, and missing paired parts contribute their correct penalties.
- Successive mutation rolls resolve in order, preventing later automatic rolls from invalidating an open choice.

Breeding and ordinary overnight mutation behavior are unchanged.

Requires the native loader, API 3 or later, and Windows Steam build 1.1.21239 / 25143593. Close the game before updating, back up your saves, and enable both the DLL and asset entry.

Not every scenario has been tested. Bug reports and feedback are welcome in the Bugs and Posts tabs.
