Good Genes 0.1.1 improves paired-mutation comparisons and fixes two mutation replacement cases.

- Matching left/right mutations now share one comparison for arms, legs, eyes, eyebrows, and ears. Different mutations keep separate comparisons, with clearer buttons for choices that affect multiple parts.
- Added spacing around the pager. Single comparisons do not reserve pager space unless a long description needs another page.
- Automatic replacements now account for the combined stat bonuses of paired parts, including the unchanged side. This prevents a replacement from lowering stats when identical paired bonuses count only once.
- Valid missing-part mutations now follow the normal mutation rules instead of being silently rejected.

Breeding and overnight mutation behavior are unchanged.

Requires the native loader, API 3 or later, and Windows Steam build 1.1.21239 / 25143593. Close the game before updating and enable both the DLL and asset entry.

Not every scenario has been tested. Bug reports and feedback are welcome in the Bugs and Posts tabs.
