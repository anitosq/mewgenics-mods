Good Genes improves breeding and gives you control over special mutation replacements.

- Kittens inherit the higher of the parents' values for each base stat.
- A mutated parent part takes priority over an unmutated part. When both parents have a mutation in the same part, either can be inherited. Native paired-part mirroring still applies.
- Random loss of part inheritance, new birth defects, and newly generated birth disorders are prevented. Existing parental defects and disorders can still be inherited.
- During events and combat, occupied stat-only mutations change automatically only when no stat decreases and at least one increases.
- When either side has a special effect, choose Keep Existing or Replace in the game. Declining consumes the roll without rerolling.

Empty parts behave normally. Ordinary overnight house mutations are unchanged.

Requires the native loader, API 3 or later, and Windows Steam build 1.1.21239 / 25143593. Close the game before installing, back up your saves, and enable both the DLL and asset entry in your mod manager.
