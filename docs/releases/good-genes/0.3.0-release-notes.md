Good Genes 0.3.0 adds guaranteed parental skill inheritance and reduces repeated work in mutation comparisons.

- Kittens inherit up to two distinct parental active skills and one eligible parental passive, chosen from both parents' combined unique skills. Stimulation no longer affects these inheritance chances, and class skills receive no preference.
- Empty parents and duplicate active skills cannot waste an available pick. Active upgrades are removed as in the base game. Skill Share's native exception remains, and skill-slot limits are unchanged.
- Mutation choices reuse their prepared descriptions when opening and changing comparison pages.

Existing kittens and ordinary overnight mutations are unchanged.

Requires Mewjector API 3 or later and Windows Steam build 1.1.21239 / 25143593. Close the game before updating, back up your saves, and enable both the DLL and asset entry.
