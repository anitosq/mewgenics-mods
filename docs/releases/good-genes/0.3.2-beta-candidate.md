# Good Genes 0.3.2.beta candidate

Owner request, 19 October 2026: apply asymmetric inheritance only to mutations.
Two ordinary inherited sides should use native mirroring; a mutation in one
pair must not cause ordinary pairs elsewhere to become asymmetric.

Based on upstream f4d3f668275489061aee42b755f5b9de88ce6607 (Good Genes 0.3.1).
No published archive or tag is replaced. This is preparation for owner testing,
not approval to publish, install, launch, execute tests or modify saves.

## Changes

- Mirror only pairs whose two selected definitions are confirmed ordinary.
- Preserve each inherited side for mutated, defective or unknown pairs.
- Keep five native random draws in their original order and direction, moving
  them to the existing final part hook and bypassing their original blocks.
- Keep matching-mutation deduplication and final head visibility native.
- Update birth logs, player documentation and deferred regression checks.

## Verification

Static inspection of the supported executable confirmed all five pair offsets,
copy directions, 1.0 scale, 0.5 threshold, TLS state, unconditional final part
selection under the loss gate, and the instruction boundaries of the bypass.
Compilation and package verification pending. Regression checks are authored
but not executed. Gameplay remains unverified, per the owner-only testing rule.

## Owner checks

1. Breed two mutation-free cats with different ordinary appearances. Arms,
   legs, eyes, eyebrows and ears should each match left/right.
2. Breed a cat with a mutation on only the left, then only the right side.
   Preserve that side while unrelated ordinary pairs remain matched.
3. Breed split Bolt/Fire eyes, matching mutations, and competing mutations
   in both parents. Preserve independent selection where a mutation exists.
4. Include inherited defects and heads that hide facial parts; save/reload
   and breed the next generation. Existing cats should remain unchanged.
5. Check birth logs and an event/combat mutation comparison for regressions.
