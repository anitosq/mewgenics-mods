# Good Genes 0.3.0.beta.2 candidate

Prepared 11 October 2026 at the owner's request to optimize Good Genes while
including the recent unpublished 0.3.0 beta changes. Public stable remains 0.2.0.

## Baseline and scope

Installed metadata reports 0.3.0.beta from 8f70667af248183ab56f4ca3cf0423fef4b336bd;
installed DLL SHA-256 is
`2ee06ea9c61e2196f94401a5bed18a8e9d7afe46bbe2246bb2059485ff4d9edc`, matching the
original frozen candidate. The current loader log records this version enabled.
Read-only inspection confirms parental skill inheritance is present. No saves
were read or changed, and no installation, deployment or game launch performed.

The only runtime optimization reuses the wrapped mutation descriptions already
prepared when opening a choice. Initial rendering and page changes no longer
repeat description generation, localization and wrapping. This is event-driven
work, not an identified idle-frame lag fix; no FPS improvement is claimed.

For N displayed comparisons, description/wrap pairs change from 2N+2 at opening
to 2N; each page change avoids another two pairs. These are static call counts,
not measured timings. Storage is one fixed 240 KiB text buffer for the active
offer. New/queued offers prepare all pages again. Unavailable or oversized text
still prevents the choice from opening, and acceptance revalidates native state.

Guaranteed parental skills, mutation policy, native hooks, random sequence,
UI assets, install mappings and safety guards are preserved. No breeding code
or skill-pool algorithm was changed. Existing archives remain untouched.
