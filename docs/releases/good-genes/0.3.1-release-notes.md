Good Genes 0.3.1 preserves asymmetric mutation inheritance and adds birth logs.

- Left and right arms, legs, eyes, eyebrows and ears now keep their separately inherited parts. This prevents a split pair from becoming identical or an ordinary side from overwriting a single-sided mutation at birth.
- Each birth logs inherited base stats, selected parental skills and part IDs in `mod_logs/chainloader.log`. The startup message confirms version 0.3.1 is enabled; unknown parental definitions report a fallback to native inheritance.

Ordinary paired appearances also inherit separately. Matching mutations still count once, and the inherited head can hide facial parts and their effects. When both parents have different mutations on the same side, the kitten inherits one. Existing kittens and ordinary overnight mutations are unchanged.

Requires Mewjector API 3 or later and Windows Steam build 1.1.21239 / 25143593. Close the game before updating, back up your saves, and enable both the DLL and asset entry.
