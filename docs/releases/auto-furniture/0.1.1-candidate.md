# Auto Furniture 0.1.1 candidate

Prepared 1 October 2026 after publishing Improved Inventory 0.3.4.
Awaiting the user's in-game test; no 0.1.1 tag, upload or publication yet.

## Scope

The global button hit hook now checks whether a mod panel is open before
reading native furniture-mode state. Controls remember whether the mod showed
them, so hiding an already hidden control does not reread its native object.
Showing and the first hide retain generation/dead-state validation. No frame
cache, new hook, solver, placement, Undo or asset change is introduced.

## Offline evidence

- The new UI fixture failed against the original closed-panel hit hook.
  It passes with the patch: 400 closed-panel hits perform zero mod reads
  while retaining all 400 native calls. An open panel still validates four
  native fields before blocking a hit; paused or stale owners pass through.
- First hide validates the renderer and hides it; repeated hide performs no
  reads. Reopening, recycled generations and dead renderers are covered.
  The idle-update fixture performs five owner/scene reads per update,
  independent of its retained hidden panel. Closing still cancels calculation.
  These are fixture operation counts, not FPS or proof of the reported lag's cause.
- Zig 0.15.2 release and diagnostic builds passed warnings-as-errors. The
  builder runs the UI fixture with assertions explicitly enabled; the fixture
  rejects assertion-disabled compilation.
- All six existing offline checks passed, including compiled native snapshot
  guards and missing/disabled/mismatched assets, external/Unicode paths,
  sibling/nested DLL placement and ambiguous copies.
- Solver checks passed with assertions enabled, including scoring, placement,
  targets/caps, supports, utility fill and input validation.
- Mewtator service revision `dd48fd8c04c9257af346363bd8fc7384308fd587`
  passed external DLL discovery, manifest, enabled/disabled asset gating and
  cleanup with the frozen archive in temporary directories.

The unchanged Vortex/FOMOD route inherits 0.1.0's live installation coverage.
