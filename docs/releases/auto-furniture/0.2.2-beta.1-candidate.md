# Auto Furniture 0.2.2-beta.1 candidate

Prepared 11 October 2026 at the owner's request to resolve the performance-audit
findings. Stage: offline checks passed; final frozen package pending. Public
stable remains 0.2.1. No installation, deployment, game launch or save access.

## Scope

- Main panel content snapshots selections, bounds, focus, room, status/counts,
  language revision and completed plan values. Unchanged content skips formatting
  and text validation/submission. Pins caches page/list/pin/language changes.
- Hiding or recreating a control invalidates its content. Failed text lookup
  retries; an explicit text-written bit distinguishes an initialized empty label.
  Native control lifetime checks, icon positioning, hover and button state remain
  in the per-frame flow. The shade and tooltip skip feedback lookup because their
  generated assets contain no feedback controls.
- Search checks cancellation/deadlines inside placement and rebuild batches and
  merge-sort passes. Partial trials never replace the best layout unless already
  valid. Utility fill shares the worker's 1.2-second budget, reserving up to its
  last 100 ms when utility candidates exist. This changes how much search/fill
  can finish under a time limit; it does not promise exhaustive filling.
- Stable merge sort replaces insertion sort; five area divisors per item are
  reused across iterations. Scoring, ties, random sequence, shape rules, limits,
  transfer validation, rollback and Undo are unchanged. The UI also avoids
  reading worker-owned best stats until the completed result is available.

## Evidence

Baseline release build/UI and solver checks passed before edits. Candidate checks:

- Release and diagnostic DLL compilation with warnings as errors.
- Production content fixture: 600 unchanged main-panel calls and 600 unchanged
  Pins calls each add zero native reads, child lookups and text writes after warmup.
  This excludes retained per-frame geometry/hover/lifetime work; it is not FPS.
- Content checks cover typing/focus, selection, utility state, plan completion and
  invalidation, language refresh, empty labels, recreated controls, missing-child
  retries, Pins toggles, paging and empty lists. Existing hidden-panel and lifetime
  checks remain passing.
- Stable sort agrees with prior insertion order at 2,048 items for ascending,
  descending and tied priorities. Cancellation is injected inside main/utility
  placement and dependency rebuilding; the best result remains valid. Deadline
  and cancellation flags are checked independently.
- Full solver cases pass: five-stat scoring, targets/caps, utility filling,
  supports, bounds, occupancy precedence, horizontal flips and legacy layouts.
- Eight Python checks pass, including release asset guards, snapshot safeguards,
  localization and 730 language round trips. DLL checks use a non-game process;
  synthetic save fixtures exist only in temporary directories.
- Paired 0.2.1/candidate harness: four scenarios, 80 iterations each, 64/512 items;
  complete best-layout/order/random-state fingerprints match `aa87291940b9abc6`.
  One illustrative run took 84.938 ms before and 79.069 ms after; these are local
  fixture timings, not a reliable percentage estimate or measured game frame time.
  Harness retained under ignored `work/auto-furniture-performance-20261011/`.

Undo and Return actions. Check:

1. Open/close the wand and Pins; hover controls and move the house camera.
2. Type/edit/clear Min/Max, change stats, toggle utility inclusion and Clear.
3. Toggle pins, page the list, reopen it, and change language then reopen.
4. Calculate with few and many pieces, with utility inclusion on and off.
5. Close while calculating, reopen and calculate again; check prompt cancellation.
6. Apply, Undo and Return; verify item counts, placements and labels.

No owner gameplay result or in-game performance measurement yet. No further
changes to synchronous snapshot/transaction algorithms are included without
