# Auto Furniture 0.2.1 publication record

The owner authorized publication on 6 October 2026 after being told the patch
and regression check compiled, but tests were not run. This release does not
claim to fix the separately reported temporary lag after closing Storage.

## Scope and evidence

Calculate and transaction restoration snapshot placed-piece entry pointers once
per operation instead of rereading them for each furniture record. Duplicate,
ownership, placement and rollback checks remain unchanged. The snapshot is local
to each call and is not reused after native scene mutations. Solver cancellation,
UI assets, translations and installation layout are unchanged.

The regression check covers read counts, duplicate entries, refreshed snapshots,
null entries, empty lists and unreadable memory. It was compiled with assertions
enabled and warnings as errors, but not run at the owner's instruction. No game,
fixture, manager-install or startup runtime testing was performed for this patch.
Unchanged coverage is inherited from 0.2.0, not claimed as fresh verification.
