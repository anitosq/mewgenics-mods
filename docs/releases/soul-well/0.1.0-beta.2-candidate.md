# Soul Well 0.1.0-beta.2 candidate

Scope authorized 2026-10-16: allow max_range edits, make activation failures
clear and fix related issues. Prepare a local installable beta. No deployment,
game launch, save changes, GitHub publication or Nexus work in this session.

## Reproduction and changes

The exact beta.1 ZIP was extracted to a temporary directory and its exported
startup gate called. Original max_range 1 returned ready; changing only that
value to 10 returned disabled. This matches the recipient's report that
restoring 1 restored correct summons. No inventory limit was reached.

Beta.2 compares GON tokens, allowing positive integer max_range values and
balanced passive-body changes. Formatting/comments/CRLF/BOM are accepted in
all supplied GON files. Core changes, duplicate fields and malformed editable
blocks are rejected. Complete baseline text replaces the brittle generated
prefix/suffix split at the first closing brace.

Activation errors produce specific log reasons and a deferred Windows dialog.
On a supported executable after successful hook installation, data rejection
keeps a guard that finishes SoulWell casts without spawning. Other items pass
through. Unsupported executables or hook failures cannot safely promise that
guard, and the dialog tells the player not to use the item. A missing DLL
cannot notify. Cast logs include scan counts and each requested jar ID.

## Validation

Native assertions pass for supported range/passive edits, core/duplicate-field
rejection, malformed nested blocks, notification content for every startup
error, blocked inactive SoulWell casts, unrelated source pass-through and all
previous capture/trampoline/partial-hook regressions. A 380-item list with
20 jars yields five unique IDs and 15 duplicates without mutation.

Source DLL checks pass for both manager layouts, exact paths, specific missing
file reasons, range 10 plus passive edits, formatting/CRLF/BOM, invalid ranges
and extra-definition rejection. Data merge scope remains unchanged.

The actual dialog, fullscreen focus, range-10 combat and customized passive
effects are pending owner/recipient testing. Fixtures do not establish those
live results. Original install and saves are untouched.
