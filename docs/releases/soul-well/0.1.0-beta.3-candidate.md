# Soul Well 0.1.0-beta.3 candidate

Scope authorized 2026-10-23: permit item edits for the recipient's unbreakable
customization in the next version. Prepare an installable local beta. No
publication, installation, launch or save changes.

The item validator now requires one SoulWell definition with kind trinket,
ability tk_SoulWell and aux -1. Other fields can change, be added or reordered.
It reuses the existing bounded container scanner and rejects malformed
structure, duplicate protected fields, missing links and extra definitions.
The shipped item and native hooks are unchanged. Range/passive customization
and startup diagnostics from beta.2 remain in place.

Native assertions pass for reordered item fields, a durability edit, nested
passives, comments/BOM, missing/changed/duplicate protected fields, malformed
values, embedded NUL and extra roots. Existing ability validation, capture,
trampoline, partial-hook and inactive-cast assertions also pass. Source-DLL
fixtures accept item edits together with range 10 and summon-passive edits
in both layouts; rejected item data reports SW_ITEM. The durability fixture
checks DLL acceptance only; it does not establish the game's durability rules.

Inherited manager coverage: beta.2's Mewtator discovery/import and Vortex
association fixtures. Package layout and discovery have not changed. Gameplay
for item edits, unbreakable behavior, save/reload, range 10 and the actual
startup dialog remain pending. The recipient's positive Armor Specialist+
report describes beta.1 only.

Stage: source validated; frozen archive verification pending.
