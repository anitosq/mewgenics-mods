# Soul Well 0.1.0-beta.1

First GitHub-only prerelease, authorized by the owner on 2026-10-15.
Nexus publication is explicitly deferred. No game deployment, launch or save
changes are part of this release session.

The release removes the disposable inventory marker, retains native state
validation and adds an explicit data-path/core-definition startup gate.
The `additional_passives` body remains editable without rebuilding the DLL.
Tracy's consumable Item offers are changed to a direct SoulWell pool at $1;
all other shop fields are retained, including stock sizes and food slots.

## Evidence

Native offline assertions pass for marker-free capture, valid/missing cat
lookup, duplicate and invalid IDs, original item preservation, malformed
containers, capacity bounds, unreadable memory, small-stack thread attach,
SourceItem trampoline branches, each partial hook-install failure and passive
body edits/escape rejection.

Data checks against the installed game archive pass: only a new item and
ability are merged, and only the intended Tracy offer fields change in both
shop variants. Every stock tier includes that offer. Source asset checks pass
for nested and sibling DLL layouts, exact enabled paths, missing/mismatched
data, allowed passive edits, CRLF/BOM and rejected core mutations.

Inherited live evidence, 2026-10-14: the disposable prototype entered combat,
summoned three unique shades from stored/backpack/equipped jars, skipped two
duplicates and two invalid IDs, blocked an ordinary second cast and repeated
the same successful summon after save/quit/reload. Source jars retained their
IDs/counts. Original saves/settings were restored and save hashes verified.
This is prototype evidence, not gameplay verification of the release ZIP.

Pending owner gameplay: this packaged version's startup, Tracy acquisition,
ordinary-campaign use and customized-passive effects. Full boards, large
collections, Armor Specialist extra uses, complete adventures and uninstall
behavior are not verified. Manager fixtures do not establish live installation.
