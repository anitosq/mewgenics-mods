# Improved Inventory 0.3.0 candidate

Development build: 0.3.0-beta.2, not published. Started 2026-09-27.
Public release remains 0.2.0.

## Scope

Sets show separate Storage and Trash columns at home. "2+ pieces" restricts
both the menu and item grids to sets with two distinct item definition keys.
Copies and conditions share a key. A piece in each container qualifies; the
columns count all copies. Counts ignore search, rarity, type and set selection.
Selecting named sets intersects the qualifying set membership. Choosing No set
clears "2+ pieces"; enabling "2+ pieces" clears No set. Clear and Reset clear it.

Equipment uses the captured unassigned grid, headed Available, without a Trash
column. Assigning items can therefore change which sets qualify. Equipped
slots and the adventure Backpack remain native.

## Implementation and checks

Ownership is cached by view and metadata revisions, separately from alphabetical
menu rows. Both grid adapters gather a complete view before assigning filtered
ordinals. Existing object lifetime and indexed hit-test guards remain in place.

Offline checks passed: duplicate/condition copies, cross-container distinct
pieces, transfers, missing/unknown metadata, selected-set intersection, empty
and repopulated views, set index 255, and 600 unchanged menu updates over 1,024
items (1,024 metadata lookups total). Existing fixtures passed. These are fixture
results, not in-game frame-rate or visual claims.

Native compilation with warnings treated as errors passed. Generated assets
passed installed-font and rarity-symbol validation. Runtime inspection, transfer
checks, equipment regression and Vortex installation are pending.
