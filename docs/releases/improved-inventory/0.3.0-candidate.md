# Improved Inventory 0.3.0 candidate

Started 2026-09-27. The private candidates led to public release 0.3.0;
see the [publication record](0.3.0-publication.md).

## Scope

Sets show separate Storage and Trash columns at home. Counts include all copies
and ignore search, rarity, type and set selection.

Equipment uses the captured unassigned grid, headed Available, without a Trash
column. Assigning items reduces the Available count. Equipped
slots and the adventure Backpack remain native.

The user deferred quantity filtering on 2026-09-27. Beta.3 removes the private
"2+ pieces" option and shortens the popup. Revisit a general quantity filter or
sort for loot decisions, including thresholds beyond two, after testing counts.

## Implementation and checks

Ownership is cached by view and metadata revisions, separately from alphabetical
menu rows. Both grid adapters gather a complete view before assigning filtered
ordinals. Existing object lifetime and indexed hit-test guards remain in place.

Count fixtures cover copies and conditions, transfers, membership rebinds,
missing/unknown metadata, empty and repopulated views, set index 255, and cache
reuse over 600 unchanged menu updates with 1,024 items. Counts are built lazily
when the Sets popup opens. Beta.3 passed all fixtures, native compilation,
font/art validation and startup guard checks. Runtime checks are pending.

Previous candidates passed native compilation with warnings treated as errors
and generated font/art validation. The tests below describe those builds only.

underlying item tooltips were suppressed. No frame-rate measurement was taken.

The initial Trash heading remained visible with blank counts in equipment.
Beta.2 starts that dynamic field empty so an empty cached value cannot leave
its initial label on screen. Equipment recheck and home transfer test pending.

Saved and quit normally. The session preserved logs and restored the original
empty slot 3; the main campaign and loader config were byte-for-byte unchanged.
