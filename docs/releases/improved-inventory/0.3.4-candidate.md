# Improved Inventory 0.3.4 candidate

Prepared 1 October 2026. Publication is pending the user's in-game test.
This patch groups adjacent native memory reads for object identity and drawer
components. Every use still validates current generation and vtable; native
layout callbacks and tooltip cleanup remain enabled. No frame-level cache,
new hook, UI change, asset change, or save change is introduced.

## Offline evidence

- Python, browser model, native filter/search/set-cache, hook, lifetime and
  hit-test fixtures passed.
- The new layout fixture exercises actual layout and hit-hook code with
  synthetic house and equipment objects. At 400 items, validation/layout
  reads fall from 8,400 to 4,400 for the house and 6,800 to 3,600 for equipment.
  All 400 native layout calls remain. These are operation counts, not FPS.
- Missing component pointers, partially unreadable objects, changed item IDs,
  recycled drawers and invalidated owners are rejected. Existing lifetime
  tests also cover changed vtables and null references.
- The corrected external-mod order passes the full Personal Compatibility
  Patches deployed audit, including storage, item protection and tooltip data.

The package, compiler, executable guards, UI assets and manager mappings use
the existing 0.3.3 workflow. Full manager lifecycle coverage carries forward;
new build and package checks will be recorded below after packaging.

## User test before publication

Install the frozen 0.3.4 ZIP with the game closed. Check the crowded house
before and after Auto Furniture, then Storage/Trash scrolling, filters and
tooltips. Check pre-adventure equipment, then return to the house. Use a copied
campaign for transfers or other actions that change saved state.
