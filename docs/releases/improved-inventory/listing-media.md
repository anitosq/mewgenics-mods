# Improved Inventory listing media

Prepared and uploaded 25 September 2026 to the
[Improved Inventory listing](https://www.nexusmods.com/mewgenics/mods/526).
The approved cover is the thumbnail; the wide header and all three supplied
screenshots are uploaded with captions. The header crop and rendered page
were visually checked before publication.

Use the files in `outputs/listing/improved-inventory/`, or the sibling
`ImprovedInventory-listing-media-v2.zip`. This ZIP contains the listing artwork.

| Placement / order | File | Caption |
| --- | --- | --- |
| Primary cover / thumbnail | `00-improved-inventory-cover-v2.png` | Improved Inventory |
| Wide page header, if offered | `header-improved-inventory-v2.png` | Improved Inventory |
| Gallery 1 | `01-storage-and-trash-scrolling.png` | Readable Storage and Trash grids with scrolling indicators |

| Gallery 3 | `03-global-search.png` | Search across item names, descriptions and set names |

The cover is 1920 x 1080. The header is 1400 x 400. All three screenshots are
2417 x 1360 and remain unchanged from the supplied Downloads files. Check
Nexus's live thumbnail and header crop previews before publication.

The cover/header use screenshot item tiles and actual game-font glyphs,
composed directly with the author's approval. The title is the only added
text. The font's small-cap letterforms are intentional. See
[artwork provenance](banner-prompts.md) for source details and the superseded
AI concepts; do not upload the older unversioned cover/header by mistake.

`media-manifest.json` records the selected files' dimensions and SHA-256 hashes.
The ZIP contains these five PNGs, this guide, the artwork provenance, and that manifest. Editable SVG
versions stay alongside the local PNGs and are not included in the upload kit.
Artwork credits are recorded in [the provenance notes](banner-prompts.md).
