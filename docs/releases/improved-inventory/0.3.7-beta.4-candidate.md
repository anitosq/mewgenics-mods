# Improved Inventory 0.3.7-beta.4 candidate

Prepared 11 October 2026 following owner approval to continue performance work.
Beta 3 remains responsive after closing. The reported Trash restore limitation
was confirmed by the owner to be the native capacity limit after disabling an
uncapping mod; no transfer or capacity change belongs to this candidate.

## Change and boundaries

Toolbar and set-popup text formatting/submission now runs only when its inputs
change, a displayed control is recreated, or a text field is not ready. The
cache covers queries, cursor/selection/focus, filters, selected sets, popup mode,
set paging/catalog size, container counts, equipment mode and existing view and
metadata revisions. Set rows and ownership retain their existing caches; paging
is clamped before content is compared. The content cache holds no game pointers.

Control creation invalidates content even if filter inputs are unchanged. Text
submission reports missing renderer/movie/text children so the next update
retries; it keeps the existing per-field text cache. Position, scale, visibility,
hover/pressed feedback, disabled-button state and native lifetime checks still
run each update. The beta-2 closed-panel guard and beta-3 drawer changes remain.

The toolbar update and query-label function were moved intact into a header
before adding the refresh gates, allowing the fixture to execute the production
update flow with simulated rendering. Other widgets and input handlers remain
in their existing file. No native hooks, dependencies, save format or item
containers were changed.

## Evidence and validation

A paired local harness uses the beta-3 toolbar source from Git and the candidate
with identical simulated rendering. Over 600 unchanged updates after warm-up:

| View | Beta 3 text submissions / label formats | Candidate |
| --- | --- | --- |
| Toolbar | 1,800 / 1,800 | 0 / 0 |
| Set popup | 16,200 / 15,000 | 0 / 0 |

Both retain 600 feedback updates and follow panel movement. Text submissions
count calls into iq_text, not native SetText calls: beta 3 already suppressed
unchanged native writes. This removes formatting and repeated text-path checks,
not previously repeated native rendering. These are fixture counts, not FPS.
The paired harness is under work/inventory-toolbar-20261011.

The new native_ui fixture runs the production toolbar flow, content cache and
set-row cache. It checks typing/caret/selection, filter changes, selected sets,
transfers/counts, view/metadata invalidation, paging/clamping, empty results,
recreated controls, delayed text/movie children, equipment labels and closing
and reopening. Rendering boundaries and ownership counts are simulated; native
control lifetime and ownership calculations retain their separate fixtures.
Full reader/browser/native regression checks passed during development.
