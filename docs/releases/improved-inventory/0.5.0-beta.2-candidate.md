# Improved Inventory 0.5.0-beta.2 candidate

## Stage and scope

Prepared on 22 October 2026 during PR preparation, after the owner accepted
0.5.0-beta.1 ("Nickel") and asked for item counts in the Stats and Effects
menus. It is 0.5.0-beta.1 plus those counts and fixes from a full-branch code
review. No installation, deployment, game launch or save access was
performed.

## Changes

- **Counts:** each Stats and Effects choice shows the number of items in
  the current view that match it, for example "Défense divine (3)". At home
  this means Storage and Trash; for equipment and the Backpack, the available
  items. Like set counts, the numbers ignore the other filters and are
  rebuilt only on a grid capture or item rebind
  (`inventory_trait_counts.h`). The popups widen: Stats buttons are 170
  units and effect toggles 226 units, both at 16 pt.
- **Review fixes** (an independent read-only review of `main...HEAD`; each
  finding was checked against the code):
  - A Storage size equal to a capacity outside 5/6/7/8/10 (9, 12) was
    offered but rejected when settings were read back. It now round-trips
    (2–20), and a UTF-8 BOM is skipped.
  - The Effects popup has 19 hover overlays, but controls kept 18, so Done
    never highlighted. The limit is now 24.
  - Grid-size clicks relayout retained background renderers long after a
    capture. Each one is now revalidated (transform link and generations)
    first, as `iq_before_grid` already did.
  - Pre-adventure equipment used the raw Storage setting. It now uses the
    capacity-limited size the button shows.
  - Stale comments and asset placeholders were updated. The count field now
    ends before the size buttons (300 units).

## Offline checks

- Python reader tests, browser model tests and all native fixtures pass.
  New cases cover the 9 and 12 round trips, out-of-range sizes, the BOM,
  menu count tallies and count labels.
- Measured with the game font at 16 pt, French labels with three-digit counts
  fit. "Constitution (+) (999)" takes 157 of 164 units, and
  "[x] Régénération de PV (999)" takes 215 of 216.

## Owner test required

- Open Stats and Effects at home, in equipment selection and in the Backpack.
  Check that the counts match what selecting a choice shows (with no other
  filter), and that they update after moving items.
- Hover Done in Effects. Check that the wider popups fit on screen.
- With an unusual Storage capacity, if available, pick the full size and
  restart.
