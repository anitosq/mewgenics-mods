# Improved Inventory 0.4.0-beta.3 candidate

## Stage and scope

Diagnostic beta prepared on 22 October 2026 for the owner's request to bring
inventory tools to the adventure Backpack screen. It is 0.4.0-beta.2 plus
read-only probes. The probes only log: they do not change the Backpack, any
item, input or layout. Stable builds compile none of this code. No
installation, deployment, game launch or save access was performed.

The Backpack screen's native objects are unknown. In the supported build,
the pre-adventure equipment grid (`InventoryScreen2`, RVA `34be50`) is only
adapted when its field `+0x58` equals 1; other values may include the
Backpack. That is a hypothesis to test, not an established fact.

## Probes (beta builds only)

All lines start with `Adventure probe:` in `mod_logs/chainloader.log` and
carry a millisecond tick for ordering against the existing activity lines.

1. **Renderers:** each distinct UI symbol name created through the game's
   renderer factory, with the calling code's RVA (at most 1024 entries).
2. **Equipment grid:** each `34be50` call with `+0x58` other than 1 (at most
   60): owner address and vtable RVA, caller RVA, and the 32-bit fields
   `+0x50` to `+0xc8`.
3. **House drawers:** each distinct owner of a house drawer callback (`213ac0`)
   that the mod does not manage, with drawer and owner vtable RVAs.
4. **Equipment drawers:** the same for the equipment drawer callback (`34e280`).

Each probe deduplicates its entries and stops at a fixed count. A drawer
callback that repeats its previous owner costs one comparison. Pointer
reads use the existing guarded reads.

## Owner diagnostic session

Use a backed-up campaign copy. With Vortex deployment idle:

1. Close the game. Install 0.4.0-beta.3 through the usual manager.
2. Launch normally. At home, open Storage once, then close it.
3. Start an adventure. Open the Backpack, scroll or move an item if the
   screen allows it, then close it. Repeat once in a later room or after a
   battle.
4. Quit through the game menu.
5. Before launching again, copy
   `Mewgenics/mod_logs/chainloader.log` and send it, with a short note of
   what you opened, in which order and roughly how many items the Backpack
   held.

The log identifies which native screen, grid and drawer classes the Backpack
uses. The next step is a design for search, filters and the Trash-style grid
there. Nothing in this beta proves that this design is feasible yet.
