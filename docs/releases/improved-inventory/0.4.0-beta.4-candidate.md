# Improved Inventory 0.4.0-beta.4 candidate

## Stage and scope

Prepared on 22 October 2026 after the owner's 0.4.0-beta.3 session (log
10:59–11:02, Mewtator, campaign with 29 Storage items and an empty Trash).
It includes the 0.4.0-beta.2 feature set and keeps the beta.3 probes. No
installation, deployment, game launch or save access was performed.

## Owner findings from 0.4.0-beta.3

- Storage never exceeded 7x7. Log: `columns 6/4 of 7/4`. The native Storage
  grid was 7 columns for 29 items, which matches the owner's 49-slot
  capacity. Sizes above 7 kept 7 because only 49 native backgrounds exist.
- Trash sizes made no visible change while Trash was empty: its native grid
  was 4x4, the game's minimum.
- The owner confirmed opening the adventure Backpack at 11:00:04. The probe
  logged an `InventoryScreen2` grid (vtable `f13d00`, layout `34be50`,
  called from `34a6bd`) in mode 0 (`+0x58`). It had 5 native columns,
  25 backgrounds (`+0xbc`) and 38 drawers (`+0xac`, equipped items
  included). This is the screen used for equipment selection in mode 1.

## Changes

- **Storage sizes:** the last house view's native Storage columns limit the
  button. It offers the listed sizes below the capacity and the capacity
  itself (5x5, 6x6, 7x7 for 49 slots). A stored larger value shows as the
  capacity. Before any house view, the full list applies.
- **Fixed Trash:** before the native house grid layout (`211700`), a fixed Trash
  size raises the stored Trash column count (`+0x54`) when it is below the
  size. Static reading shows that this count only grows (minimum 4). It
  is not reset, so the game builds the chosen backgrounds itself. This is
  the mod's only write to a native layout field. It is skipped for Auto,
  and it requires both house panels and a readable count from 2 up to the
  size. A changed size applies at the next Trash grid build.
- **Backpack:** equipment capture accepts mode 0 in addition to 1. Mode 0
  uses the Trash size (fixed or Auto); mode 1 keeps the Storage size.
  Equipped items stay native through the existing assignment check (`34bcb0`).
  Toolbar, search, filters, set list, scrolling and hidden-item click
  rejection reuse the equipment path unchanged. The set list header reads
  "Available".
