# Listing artwork provenance

## Selected artwork: direct composition (v2)

On 25 September 2026, the author requested actual game assets arranged in an
organized, faded background and the game's font. The author then approved
direct composition instead of AI generation.

The selected cover is `00-improved-inventory-cover-v2.png` (1920 x 1080).
The selected wide header is `header-improved-inventory-v2.png` (1400 x 400).
Both are in the local ignored `outputs/listing/improved-inventory/` folder.
Their editable SVG versions stay local in the same folder.

- Item tiles are cropped from the author's first gameplay screenshot,
  arranged in an aligned grid, and faded behind the title.
- Title paths use the actual `Edmundm` font glyphs from the installed game's
  `swfs/fonts.swf` (font ID 6, `EdmundMcMillen_INTLv4 Regular`). No substitute
  font and no generated lettering are used in v2.
- Only the title's required glyphs are rendered into the artwork; no reusable
  font file is distributed. The native font naturally renders small capitals.
- The three gallery screenshots remain byte-for-byte unchanged.
- These media are separate from the frozen mod archive. Game-derived artwork
  and lettering are not licensed under the repository's MIT source-code license.

Both PNG exports were visually inspected, including reduced thumbnail previews.
The live Nexus upload/cropping preview remains to be checked.

## Cover prompt

Use case: ads-marketing. Asset type: main Nexus Mods listing cover/banner for a Mewgenics inventory mod. Create a finished 16:9 landscape image, ideally 1920x1080. The entire design is typography on a subtly textured warm off-white paper background with a restrained charcoal outer edge, evoking handmade ink-and-paper game UI. Exact and ONLY text, case-sensitive: "Improved Inventory". Set it on two centered lines: "Improved" above "Inventory". Very large, bold, slightly irregular hand-inked rounded letters with a charming understated roughness, dark near-black ink, generous spacing, perfectly legible at small thumbnail size. Keep the whole title within the central 80% of width and central 65% of height. Use title case exactly as specified. The paper grain and tiny edge wear are quiet and subtle, center clean and high contrast. Professional balanced typographic composition, flat frontal view. No subtitle, no tagline, no version, no author credit, no other letters or numbers, no watermark, no icons, no cats, no inventory illustrations, no game logo, no buttons, no extra objects. Deliver the actual finished banner image.
