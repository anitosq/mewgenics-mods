# Improved Inventory Nexus listing copy

Release 0.3.4. Mirrors the live description on 1 October 2026.

## Summary

Find what you need at home and before an adventure. Adds readable scrolling grids, search, and filters for item type, rarity and sets to Storage, Trash and equipment selection.

## Description

A crowded inventory is hard to sort when every icon keeps getting smaller. Improved Inventory gives Storage and Trash scrollable grids with readable item icons, plus search and filters to help you find what you need. The same controls are available while choosing your cats' equipment before an adventure.

- Find items by name, description or set name.
- Show consumables, reusable weapons, worn items or broken items.
- Narrow results by rarity, from Common to Very Rare.
- Browse sets, see separate Storage and Trash counts, and select several sets at once. During equipment selection, see how many items are still available.

Search and filters work together, so you can look for something specific, like Rare consumables or equipment from a particular set.

## Requirements

Windows x64, Mewgenics 1.1.21239 (Steam build 25143593), and [Mewjector](https://www.nexusmods.com/mewgenics/mods/218) API v3. This release supports that game build only.

## Install with Vortex

Close the game. Install and enable Mewjector if you don't already use it, then download, enable and deploy Improved Inventory. Launch Mewgenics through Vortex.

See the [installation guide](https://github.com/anitosq/mewgenics-mods/blob/main/mods/improved-inventory/INSTALL.md) for setup help and compatibility details. Controller support hasn't been tested.

## Install with Mewtator

Import the same ZIP into Mewtator, enable the mod and DLL Mod Support, and launch through Mewtator. Your mods folder can be outside the game directory.

If switching mod managers, remove your previous installation first, including its DLL.

For manual installation, follow the installation guide.
