## Installation copy correction

Read the author's current Nexus description before editing. It had already
removed the separate extension installation step. The local Vortex setup has
the Mewgenics extension 0.4.0 installed; this does not establish how it was added.
The [extension author's guidance](https://www.nexusmods.com/site/mods/1691) requires
launching with Vortex's default game tool so mod paths are supplied. The installed
extension registers Custom Launch as that default tool.

The listing and install guide now tell players to enable and deploy the mod and
launch through Vortex, with Mewjector as the only mod dependency. A working
Mewgenics Vortex setup needs no separate extension download for this mod. New
users are directed to Vortex's game setup prompts.
