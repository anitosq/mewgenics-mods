# Improved Inventory 0.3.8-beta.1 candidate

## Stage and scope

Prepared for owner testing on 11 October 2026. The owner reports that 0.3.7
keeps the house smooth after closing Storage, but the open inventory still
lags with 500+ items. This beta addresses repeated native drawer work and
metadata scans. It is not a published release or full presenter virtualization.
Installed mods and saves remain unchanged; no game launch or deployment.

## Implementation evidence

- The supported executable's house drawer callback at RVA `0x213ac0` performs
  a `ref_grid` bounds lookup and transform interpolation on every call. Its
  panel-tracking branch runs when current and target panels differ; its hover
  branch runs when button state is 1. Native button updates are independent.
- Skip that callback only for already hidden house drawers with unchanged
  identity, owner, panels, components and layout targets, an invisible renderer
  and idle button. Validate the retained view references on every callback.
  Scrolling/filtering restores presentation when the drawer becomes visible.
- Reuse the manager snapshot within the same callback, without an intervening
  native call. No frame/time-based lifetime cache: no safe shared frame boundary
  has been established. Guarded-read counts remain similar to 0.3.7.
- Preserve native updates for visible/hovered/pressed/changed drawers, closed
  inventory and stale views. Equipment uses its existing update path. Native
  button updates remain enabled for mouse-leave and tooltip cleanup.
- Replace metadata linear scans with the existing pointer-index pattern. Ring
  eviction removes the previous key; lookups still check item ID and generation.
- Beta builds sample one callback in 61 and log every 300 first-drawer calls.
  Logs report callback time and hidden-skip counts, not FPS or total frame time.
  Samples may include both open and closed inventory; the activity logs identify
  those transitions. Stable builds omit this sampler.

## Offline checks

- Python reader tests, browser model tests and all native assertion fixtures pass.
- Layout fixtures cover 0, 1, 16, 35, 36, 37, 513 and 1024 items, both containers,
  hover/pressed states, changed components/targets, unreadable fields, recycled
  identities, filtering, scrolling, close/reopen and stale shared references.
- With 513 settled house items, native drawer updates fall from 513 to 36 per
  fixture pass. With 400 items: open inventory has 36 native updates, 36 instant
  layouts and 3564 guarded reads; closed inventory retains 400 native updates,
  zero mod layouts and 400 reads. Equipment remains unchanged.
- Metadata fixture covers collision-chain deletion including wraparound,
  4096 bindings through the 1024-slot cache, eviction, rebinding and generations.
- The layout fixture also compiles with the beta sampler enabled and verifies
  reporting, sampling and skipped-callback accounting.

## Owner test still required

Install the beta through the usual manager after closing the game. In the
500+ item inventory, check scrolling, search/filter changes and tooltips;
transfer a few items between Storage and Trash, then close and reopen it.
Check that returning to the house stays smooth. Empty results, fewer than
36 items and leaving the house also remain useful runtime checks.

Fixture counts prove avoided work, not smooth rendering or gameplay correctness.
No in-game FPS measurement or beta tooltip/transfer test has been performed.
Full presenter recycling and equipment callback suspension remain deferred.
