# Improved Inventory 0.5.0-beta.3 candidate

## Stage and scope

Prepared on 22 October 2026 during PR preparation, at the owner's request
for the game's base item types in the Item type menu. It is 0.5.0-beta.2
plus equipment-slot types. No installation, deployment, game launch or save
access was performed.

## Evidence and changes

- The `kind` field of the supported build's item definitions gives head (208),
  face (197), neck (189), weapon (237), trinket (275) and modifier (10). The
  first five are the cat's equipment slots on the wiki
  ([Mewgenics research notes](../../research/mewgenics-research.md)). Consumables
  share the trinket slot.
- Item type gains Head, Face, Neck, Weapon and Trinket, read from the loaded
  definition's `kind` at bind (`IQItemTraits.slot`). Unknown or other kinds
  match no slot. The menu now has two columns: the six existing categories
  and the five slots (`iq_type_rect`/`iq_type_choice`, mirrored by
  `build_filter_assets.py`).
- Labels are English like the rest of that menu. The game's only slot-name
  strings are event answers and key bindings ("Babioles", "Armes" in
  French), which would read inconsistently.

## Offline checks

- Python reader tests, browser model tests and all native fixtures pass,
  with new slot-matching and type-popup geometry cases.
