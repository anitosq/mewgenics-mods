# Improved Inventory 0.4.0-beta.5 candidate

## Stage and scope

Prepared on 22 October 2026 after the owner reported that changing the
Trash size in 0.4.0-beta.4 had no visible effect and seemed to cause a fault.
It is 0.4.0-beta.4 plus this fix; the beta probes remain. No installation,
deployment, game launch or save access was performed.

## Evidence

- Owner log, 11:37–11:38 (Mewtator, 0.4.0-beta.4, settings Storage 5 and
  Trash 5). At house load the layout reported `columns 5/4 of 7/4`, so the
  native Trash stayed 4x4 despite the setting.
- Cause: a new house menu holds 0 in the Trash column count (`+0x54`). The
  beta.4 pre-size accepted only counts from 2, so it never ran. The native
  code raises counts below 4 to 4.
- That log covers a session that did not open Storage, and it contains no
  crash line; no crash report is newer than 20 October. The fault the owner
  saw is therefore not in this log; it was probably overwritten by the next
  launch. It remains unexplained.

## Changes

- The pre-size now accepts a count from 0 up to the chosen size.
- Raising the Trash to a size its current native grid lacks now rebuilds the
  open house grid through the hooked native layout, the same path the game
  uses when it opens the menu. The log reports it as "Trash grid rebuilt for
  its new size." Smaller sizes and Auto still only reposition.
  Calling the native layout from the click handler is new. It needs an
  owner test before any stable release.

## Offline checks

- Python reader tests, browser model tests and all native fixtures pass.
- Diagnostic, release-beta and stable variants compile with `-Werror`.

## Owner test required

Use a backed-up campaign copy. Copy `mod_logs/chainloader.log` immediately
after any session that misbehaves, before launching again.

- Open Storage/Trash with Trash set to a fixed size: an empty Trash shows the
  full grid (for example 5x5).
- While open, click Trash to a larger size: the grid grows at once. Then move
  items between Storage and Trash, scroll, and close and reopen it.
- Smaller sizes and Auto: the grid follows without errors.
- If the earlier fault returns, describe what happened (freeze, crash,
  wrong display) and send that session's log.
- The beta.4 Backpack and Storage checks still apply.
