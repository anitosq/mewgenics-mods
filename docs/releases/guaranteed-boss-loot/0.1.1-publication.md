# Guaranteed Boss Loot 0.1.1

Status: published on GitHub and Nexus, 30 September 2026. Both downloaded
archives verified byte-for-byte against the frozen local release.

Independent data-only mod; no Mewjector dependency. Version 0.1.0 was a frozen
private candidate. Version 0.1.1 retains identical parsed gameplay data and prepares
public metadata, installation notes and licensing without overwriting it.

The user confirmed local gameplay testing before publication. Automated checks
separately verify the installed vanilla events, the local mod collection and
that collection without NeverFailBossLooting. Only six intended fields change;
the three original reward branches remain intact. Negative controls detect a
later restored failure branch or reduced success chance.

Reference executable SHA-256:
`4127cd6a792ae528bca6f65a8873dd61789591937d87656c2b586a5e30eb77ea`.
Steam build: `25143593`.

Native evidence: event option parsing stores `fixed_chance` at option+0xA8.
Constructor RVA 0x912610, relevant parse at 0x912DE8-0x912E22, percent parser
0x9426E0. Outcome function 0x91BE20 substitutes a positive fixed chance at
0x91C157-0x91C173; >=1 takes success without RNG at 0x91C19F-0x91C1A7.
Null bad outcomes fall back to good at 0x91C3FD-0x91C423.
The originally reported upstream breakage was not reproduced; public copy
does not claim a diagnosed upstream regression.
