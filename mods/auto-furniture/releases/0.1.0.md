# Auto Furniture 0.1.0

First public release.

- Calculate and apply room layouts for any combination of the five furniture stats, with optional Min and Max values.
- Pin furniture, include utility pieces, return furniture from one or all rooms, and undo the last mod action.

Requires Windows, Mewgenics 1.1.21239 (Steam build 25143593) and
[Mewjector](https://www.nexusmods.com/mewgenics/mods/218) API 3 or newer.
Back up your saves before first use.

Install the ZIP through Vortex or Mewtator, enable the mod and launch through
your manager. In furniture-placement mode, click a room's wand, choose stats,
Calculate, then Apply. Mouse and keyboard required. The search reports its best
found layout, not a guaranteed optimum.

See the [installation and usage guide](https://github.com/anitosq/mewgenics-mods/tree/main/mods/auto-furniture).
