# Guaranteed Boss Loot 0.1.1

Collect the normal act-boss reward without losing the cat who searches.

- Guaranteed success when looting the Dead King, reaching into the Rift,
  or examining the Dead God.
- Original reward pools and successful outcomes are unchanged.
- A small data patch, with no DLL loader required.

Install the attached `GuaranteedBossLoot-0.1.1.zip` with Vortex or Mewtator.
Disable Never Fail Boss Looting and load this mod after other boss-event mods.
See the included README for manual installation and compatibility notes.
