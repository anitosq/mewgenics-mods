# Soul Well 0.1.0-beta.1

Soul Well summons a shade for each unique cat in your full Soul Jars with one
trinket use. It includes jars in home storage, your backpack and allied
adventurers' equipment. Jars stay intact; duplicate IDs summon only once per cast.

This is an experimental Windows x64 release for Mewgenics **1.1.21239**
(Steam build **25143593**) and **Mewjector API 3 or newer**.
The packaged beta and its shop acquisition have not yet been tested in-game.
Back up your saves before testing.

Download **SoulWell-0.1.0-beta.1.zip** below. The ZIP includes the compiled DLL,
loose GON files, installation instructions and a customization guide.
No `.gpak` is used. The source-code downloads are for development.

For beta access, Tracy's newly generated consumable offers sell Soul Well for
**$1**. Existing stock may need a later day's refresh. Equip it in a trinket
slot, then select a free adjacent tile in combat. It costs no mana, is a
cantrip and can be used once per fight. The item uses the Soul Jar icon.

To customize summons, edit `additional_passives` in
`SoulWell/data/abilities/item_abilities.gon.merge` and restart. The DLL accepts
these edits without rebuilding. Keep the surrounding summon definition and
other supplied core files unchanged. Soul Well's ability is separate from
the default Soul Jar's ability.

The earlier prototype summoned three unique cats and worked again after
save/reload. This beta adds ordinary-campaign support, shop access and install
packaging. Automated checks cover collection, duplicate/invalid IDs, native
hook regressions, startup guards, editable passives and package layouts.
Full boards, large collections and Armor Specialist extra uses remain untested.
Jars equipped by cats left at home are not scanned. Crowded boards may not fit
every summon.

See [installation and use](https://github.com/anitosq/mewgenics-mods/blob/soul-well/v0.1.0-beta.1/mods/soul-well/README.md)
and [passive customization](https://github.com/anitosq/mewgenics-mods/blob/soul-well/v0.1.0-beta.1/mods/soul-well/CUSTOMIZE.md).
Install Mewjector separately. This prerelease is on GitHub only.
