# Soul Well 0.1.0-beta.2

You can now change `target.max_range`, including setting it to 10, while
keeping the DLL active. `spawn.additional_passives` remains editable.
Whitespace, comments and Windows line endings no longer trigger a mismatch
in the supplied GON files. Other gameplay settings remain checked.

If the DLL loads but cannot activate, a Windows dialog explains why and points
to `mod_logs/chainloader.log`. On the supported executable with hooks installed,
a data-check failure also blocks Soul Well casts instead of producing generic
shades. A missing DLL cannot show a warning; check the log for a successful
Soul Well startup before testing.

Cast logs now include scan totals and each jar cat ID requested for cloning.
Duplicate jars still summon each cat once. The reported inventory size of
380 items with 20 full jars for five cats is covered by an offline fixture.

Replace both the DLL and data files, then reapply your range/passive edits.
The ZIP keeps all GON files loose. Requires Mewgenics 1.1.21239, Steam build
25143593, Windows x64 and Mewjector API 3 or newer.

This is a local beta candidate. Offline checks pass; range-10 gameplay and
the actual startup dialog still need testing. It has not been published.
