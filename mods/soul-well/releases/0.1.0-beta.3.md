# Soul Well 0.1.0-beta.3

Download **SoulWell-0.1.0-beta.3.zip** below. It includes the DLL and loose GON
files for editing.

You can now edit the item file, including durability settings for your own
unbreakable version, without disabling the DLL. Name, description, icon,
rarity and item passives are also editable. The shipped item is unchanged.
Keep the `SoulWell` ID, `kind trinket`, `ability tk_SoulWell` and `aux -1`.
See the included CUSTOMIZE.md for details.

Compared with beta 1, this also allows `target.max_range` edits, including 10,
and changes to `spawn.additional_passives`. Formatting, comments and Windows
line endings are accepted. If the loaded DLL cannot activate, it reports the
reason in a Windows dialog and `mod_logs/chainloader.log`. On the supported
executable with hooks installed, rejected data blocks Soul Well casts instead
of producing generic shades. A DLL that never loads cannot show a warning.
Cast logs include inventory counts and requested jar cat IDs.

Close the game before updating. Preserve your GON edits, replace both the DLL
and data files, then reapply your edits. Requires Windows x64, Mewgenics
1.1.21239 (Steam build 25143593) and Mewjector API 3 or newer.

This is a prerelease. Offline and package checks passed; edited durability,
extended-range gameplay, save/reload with those edits and the actual startup
dialog still need testing. Back up your saves before testing.
