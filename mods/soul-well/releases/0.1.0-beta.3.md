# Soul Well 0.1.0-beta.3

You can now edit the loose item file, including durability settings for your
own unbreakable version, without disabling the DLL. Name, description, icon,
rarity and item passives are also editable. The shipped item is unchanged.

Keep the SoulWell ID, kind trinket, ability tk_SoulWell and aux -1. Missing or
changed required fields still trigger the startup error. See CUSTOMIZE.md.
Range and summon-passive edits and activation diagnostics from beta.2 remain.

Replace both the DLL and data files, then reapply your edits. All GON files
remain loose. Requires Windows x64, Mewgenics 1.1.21239 (Steam build 25143593)
and Mewjector API 3 or newer.

This local beta needs gameplay testing, including edited durability and
save/reload. It has not been published.
