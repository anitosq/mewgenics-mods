# Improved Inventory 0.3.6

- Fixed a startup timing issue that could leave the mod inactive even though
  Mewjector reported that its DLL loaded successfully.

One ZIP supports Vortex and Mewtator. Requires Mewjector API v3 and
Mewgenics 1.1.21239. Close the game and replace the previous version through
your mod manager. See the included INSTALL.md for installation instructions.
