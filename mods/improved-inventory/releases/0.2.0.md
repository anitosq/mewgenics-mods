# Improved Inventory 0.2.0

Fixed the crash when locking in your cats for an adventure. You can now scroll,
search and filter Storage while choosing their equipment, just as you can at
home.

Requires Mewjector API v3 and Mewgenics 1.1.21239 (Steam build 25143593) on
Windows x64. Close the game and update the whole mod through Vortex.

[Nexus Mods / Vortex](https://www.nexusmods.com/mewgenics/mods/526) ·
[Installation guide](https://github.com/anitosq/mewgenics-mods/blob/main/mods/improved-inventory/INSTALL.md)
