First public release of Improved Inventory for Mewgenics.

## What's included

- Scrolling Storage and Trash grids that keep item icons readable, with arrows to show when you can scroll.
- Search by item name, description or set name.
- Filters for item type, worn and broken items, and rarity.
- A searchable set list with item counts and multiple selections.
- The game's font, rarity symbols and sounds. Open dropdowns block clicks and tooltips on items underneath them.

## Install

Requires Windows x64, Mewgenics 1.1.21239 (Steam build 25143593), and
[Mewjector](https://www.nexusmods.com/mewgenics/mods/218) API v3 (tested with runtime v3.0).
The mod stays inactive on other game builds. Mewjector is the only mod dependency.

Close the game. Install `ImprovedInventory-0.1.0.zip` through Vortex, enable
and deploy it, then check ImprovedInventory in Load Order. Start the game
with Custom Launch. If you used the earlier Inventory QoL test build, remove it first.
The [installation guide](https://github.com/anitosq/mewgenics-mods/blob/improved-inventory/v0.1.0/mods/improved-inventory/INSTALL.md)
has manual setup and troubleshooting steps.

## Notes

This release uses the tested beta.2 implementation with the version updated
to 0.1.0. It adds no bulk trash actions; items left in Trash are still deleted
when you end the day.

Controller and IME input, manual installation, and wider UI-scale coverage
haven't been tested. In-game performance with very large inventories also
needs testing. The repository's release checklist has the full test history.
