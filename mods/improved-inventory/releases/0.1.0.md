# Improved Inventory 0.1.0

Readable scrolling grids, search and filters for Mewgenics' existing
Storage/Trash screen.

## Features

- Fixed-size item grids with scrolling and directional indicators.
- Search across item names, descriptions and sets.
- Item-type, condition and rarity filters, plus searchable set selections.
- Game font, rarity artwork and native sound feedback.
- Dropdowns block interaction with items underneath them.

## Requirements and installation

Windows x64, Steam build **25143593** (game version **1.1.21239**), and
[Mewjector](https://www.nexusmods.com/mewgenics/mods/218) **API v3**
(runtime v3.0 tested). Other executable builds are rejected.
No other gameplay mod, Mewtator or Mewgenics Mod Manager is required.

Install `ImprovedInventory-0.1.0.zip` through Vortex, enable and deploy it,
check ImprovedInventory in Load Order, then use Custom Launch. Download the
installable archive, not GitHub's automatically generated source ZIP.
Remove the former Inventory QoL candidate before installing the renamed mod.
See the [installation guide](https://github.com/anitosq/mewgenics-mods/blob/improved-inventory/v0.1.0/mods/improved-inventory/INSTALL.md).

## Testing and limitations

The preceding candidate was user-tested with only Mewjector and this mod,
including Trash overflow, scrolling, filters, disabling, re-enabling,
removal, reinstall and the separate asset Load Order toggle. Version 0.1.0
retains that runtime implementation with finalized version metadata and
release documentation.

No bulk trash operations are included. Controller/IME input, other game
builds, manual installation and broader UI-scale coverage remain unverified.
Normal item transfers and End Day retain their effects. Large-inventory
logic has automated coverage; measured in-game performance at very large
counts and remaining release-matrix checks are still pending.
