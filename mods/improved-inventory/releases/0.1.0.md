First public release of Improved Inventory.

Storage and Trash now scroll without shrinking your item icons. Search your
loot by name, description or set, filter by item type and rarity, and see
which set pieces you own.

## Install with Vortex

Requires Windows x64, Mewgenics 1.1.21239 (Steam build 25143593), and
[Mewjector](https://www.nexusmods.com/mewgenics/mods/218) API v3.

Close the game, install `ImprovedInventory-0.1.0.zip` through Vortex, then enable
and deploy it. Check ImprovedInventory in Load Order and start the game with
Custom Launch.

See the [installation guide](https://github.com/anitosq/mewgenics-mods/blob/main/mods/improved-inventory/INSTALL.md)
for setup help and compatibility details.
