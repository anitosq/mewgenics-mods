# Improved Inventory 0.3.0

The Sets menu now shows separate Storage and Trash counts, so you can see what
you're keeping and what you're throwing away. Counts include duplicate copies
and stay the same when you search or filter the inventory. During equipment
selection, Available counts the items you haven't assigned to a cat.

Requires Mewjector API v3 and Mewgenics 1.1.21239 (Steam build 25143593) on
Windows x64. Close the game, update and deploy the mod, then launch through Vortex.
