# Improved Inventory 0.1.0-beta.2

Draft release notes — not published.

A beta that adds readable scrolling grids, search and filters to Mewgenics'
existing Storage/Trash screen.

## Features

- Fixed-size item grids with scrolling and directional indicators.
- Search across item names, descriptions and sets.
- Item-type, condition and rarity filters, plus searchable set selections.
- Game font, rarity artwork and native sound feedback.
- Dropdowns block interaction with items underneath them.

## Requirements and installation

Windows x64, Steam build **25143593** (game version **1.1.21239**), and
**Mewjector API v3** (runtime v3.0 tested). Other executable builds are rejected.
No other gameplay mod, Mewtator or Mewgenics Mod Manager is required.

Install `ImprovedInventory-0.1.0-beta.2.zip` through Vortex, enable and deploy
it, check ImprovedInventory in Load Order, then use Custom Launch. Download
the installable archive, not GitHub's automatically generated source ZIP.
Remove the former Inventory QoL candidate before installing the renamed mod.
See the [installation guide](https://github.com/anitosq/mewgenics-mods/blob/f5cd001a4884b7991a075fb084ccdf57fc763348/mods/improved-inventory/INSTALL.md).

## Testing and limitations

User-tested with only Mewjector and this mod enabled, including Trash overflow,
scrolling, filters, disabling, re-enabling, removal, reinstall and the separate
asset Load Order toggle. The latest retained log verifies inactive behavior
when that asset entry is unchecked. Earlier enabled runs verify normal startup.

No bulk trash operations are included. Controller/IME input, other game builds,
manual installation and broader UI-scale coverage remain unverified. Normal
item transfers and End Day retain their effects. Remaining release checks are
tracked in the repository; these draft notes do not certify them complete.
