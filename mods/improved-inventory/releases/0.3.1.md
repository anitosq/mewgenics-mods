# Improved Inventory 0.3.1

Mewtator users can now keep Improved Inventory in their configured mods folder,
including outside the game directory. Download the Mewtator ZIP, enable the mod
and DLL Mod Support, and launch through Mewtator.

For Vortex or a manual game-folder installation, use the regular ZIP. Install
only one version. If switching to the Mewtator download, remove the previous
installation first, including its DLL.

Requires Mewjector API v3 and Mewgenics 1.1.21239 (Steam build 25143593) on
Windows x64.
