# Improved Inventory 0.3.2

One download now works with both Vortex and Mewtator. Install it through Vortex,
or import the same ZIP into Mewtator and enable DLL Mod Support.

If updating from 0.3.1 or earlier in Vortex, remove the old version and deploy
before installing this update. Mewtator users can replace their existing mod.
Inventory features are unchanged.

Requires Mewjector API v3 and Mewgenics 1.1.21239 (Steam build 25143593) on
Windows x64.
